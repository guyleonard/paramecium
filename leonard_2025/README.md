# Leonard et al 2025 Genome Resources
## De novo genome sequence assembly of the RNAi-tractable Paramecium bursaria 186b an endosymbiotic model system
Data files, R scripts and sequence data for the *Paramecium bursaria* 186b genome sequencing project.

## Genome Assembly and Annotation
Subject to some minor changes before submission to NCBI - ongoing
